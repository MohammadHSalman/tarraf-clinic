# عيادة د. أحمد طراف — Flutter 0.4.0

تصميم عربي/إنكليزي بخط Tajawal، عملات مركزية USD/SYP، مخزون مرتبط بخرائط الحقن، دليل إجراءات، أرشيف، تقويم شبكي وتقارير بصرية. اقرأ docs/RELEASE_040_AR.md لشرح كل الوظائف وقواعد الحساب والترحيل، وdocs/BUILD.md للبناء.

1. خذ نسخة احتياطية وثبّت التحديث فوق الإصدار السابق دون حذفه.
2. حدد العملة الأساسية وسعر الصرف من الإعدادات.
3. أدخل الجرد الحقيقي وكلفة المواد قبل استخدامها؛ المخزون السابق يبدأ بصفر.
4. راجع قوالب التعليمات والموافقات واعتمدها طبياً.
5. أضف المريض واختر الإجراء، سجل النقاط والأتعاب، اعتمد الجلسة ثم سجل الدفعات.

المبالغ التاريخية ثابتة؛ المقابل بالعملة الأخرى تقديري بالسعر الحالي. كل تعديل لنقطة يعالج المخزون والاستهلاك والكلفة داخل معاملة واحدة.

## نسخة أخف حجماً

تتوفر حزمة ARM64 بحجم 28.6 ميغابايت وحزمة ARM32 بحجم 25.1 ميغابايت بدلاً من الحزمة الشاملة 79.3 ميغابايت. الميزات والبيانات والتشفير لم تتغير. اختر معمارية الهاتف الصحيحة وثبّت فوق التطبيق دون حذفه. اقرأ docs/SMALL_APKS.md لطريقة إنتاج الحزم الصغيرة وحدود التحقق.
